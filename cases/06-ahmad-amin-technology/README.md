# Ahmad & Amin Technology

**Status:** `Candidate — Phase 1 PASS · Private two-person app`

A live two-person workspace covering folders, files, meetings, checklists, and voice — built for Amin and Ahmad.

## What It Is

A live, private two-person collaboration workspace built specifically for Amin and Ahmad. Phase 1 is complete (PASS). Covers folder and file management, meeting support, checklists, and voice interaction. Personal use does not remove it from the portfolio — it is a real, live system.

## What It Is Not

- Not a public multi-tenant product.
- Not Production-Ready.
- Supabase sync is not yet live per source README.
- OpenAI model room is not yet live per source README.
- Later phases are not started.

## Problem

Two collaborators working across systems need a shared, structured workspace that handles files, meetings, checklists, and voice in one place — without the overhead of a general-purpose SaaS tool.

## Scope

Phase 1 (PASS):
- Folder and file management
- Meeting support
- Checklists
- Voice interaction

Later phases: not started. Supabase sync and OpenAI model room planned but not live.

## Architecture

Web application with shared workspace state. Phase 1 architecture documented in source repository. Supabase sync and OpenAI model room are planned future integrations.

## Engineering Decisions

- Phase-gated delivery: Phase 1 must pass before later phases begin.
- Private two-person scope: no multi-tenant design required at this stage.
- Voice included in Phase 1: reduces friction for the two primary users.
