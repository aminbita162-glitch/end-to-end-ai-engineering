# Patch-Auri

**Status:** `Non-medical informational NFC/color-guidance prototype`

A functional prototype using NFC and color-guidance to provide non-medical, informational health-adjacent guidance.

## What It Is

A functional prototype that combines NFC technology with a color-based guidance system to deliver informational output. Designed as an exploratory prototype, not a certified or regulated product.

## What It Is Not

- Not a medical device.
- Not a regulated health product.
- Not a clinical tool or diagnostic system.
- Informational only.

## Problem

NFC-enabled objects can carry context that current apps do not leverage for informational guidance. Color coding provides an accessible, glanceable signal layer. This prototype explores that combination.

## Scope

- NFC tag reading / triggering
- Color-based guidance output
- Informational (non-medical) use case
- Functional prototype stage

## Architecture

NFC interaction layer triggering a color-guidance informational output. Architecture documented in source repository.

## Engineering Decisions

- Prototype scope: validate the NFC + color-guidance interaction before expanding functionality.
- Non-medical classification enforced by design scope and documentation.
- Informational output only: no diagnostic logic, no treatment recommendations.
