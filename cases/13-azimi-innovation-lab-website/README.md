# Azimi Innovation Lab Website

**Status:** `Live public site`

The public identity surface for Amin Azimi as an AI Systems Architect, hosted under the Azimi Innovation Lab brand.

## What It Is

A live public website serving as the professional identity surface for the Azimi Innovation Lab. Presents the AI Systems Architect profile, work, and contact information publicly.

## What It Is Not

- Not a SaaS product.
- Not a client-facing application with user accounts.
- Not a portfolio management system.

## Problem

An AI Systems Architect needs a public, professional identity surface that communicates what they build, how they think, and how to reach them — separate from GitHub or LinkedIn.

## Scope

Public identity website:
- Professional profile as AI Systems Architect
- Brand presence for Azimi Innovation Lab
- Public-facing representation of work and approach

## Architecture

Static or server-rendered public website. Hosted on Vercel.

## Engineering Decisions

- Vercel deployment: fast global delivery, zero-infrastructure overhead for a public identity site.
- Separation of concern: public identity site is distinct from engineering portfolio repository.
